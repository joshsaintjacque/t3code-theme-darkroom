01

What moves, and why

Every animation is tied to real app state. If nothing is running, nothing moves. Flip the switches below to see each piece working and at rest.

A · The traymargin left

A print develops

On wide windows the left margin is a developing tray. When a turn starts a fresh print goes in: sky first, then the hills, then the deep blacks. Below it a seven-segment timer counts the seconds. At rest the print is fixed and the timer waits at 00:00.

B · The linemargin right

Wet prints hang to dry

Finished prints hang on a line in the right margin. While work runs they sway slowly on their pegs and drip. Idle, they hang straight and dry.

C · Header rulerchat header

The ruler

The foot of the header is a ruler. During a turn a glint of safelight travels along it, with no promise of when it will finish. When the turn ends the ruler flashes ivory once.

03

Palette

One hue on near-black. Red is the lamp, paper is the print, amber is the enlarger. Click a swatch to copy its hex.

Contrast: text on canvas 15.6:1 · muted 8.9:1 · print ink on paper 11.2:1 · safelight button text 6.3:1.

04

Install

Three baths. One JSON file, nothing else to fetch.

Bath 1 · Developer10 s

Copy the theme

Copies darkroom.json to your clipboard. Or download the file.

Bath 2 · Stop20 s

Add it in T3 Code

Open Settings › Appearance › Add theme, paste the JSON (or choose the file) and add it.

Download .json
Bath 3 · Fix5 min

Pick Darkroom

Choose Darkroom in the theme list. Start a turn and watch the tray.

Or from the terminal
$ curl -fsSL -o darkroom.json https://joshsaintjacque.github.io/t3code-theme-darkroom/darkroom.json
$ ~/.t3/bin/t3 theme set darkroom.json

Tested on T3 Code 0.1.11 (nightly). t3 theme set sets the theme for every client connected to that environment.
